# Protonesk

Use your ProtonMail account (free plan included) in any standard email client —
Thunderbird, Apple Mail, Outlook, mutt, etc. — over plain IMAP/SMTP.

Protonesk is a thin Windows auto-start wrapper around
[hydroxide](https://github.com/emersion/hydroxide), a third-party bridge that
talks to ProtonMail's web API and exposes local IMAP, SMTP, and CardDAV
servers. Everything runs on `127.0.0.1`, never on the network.

> **Note:** the official Proton Mail Bridge requires a paid plan. hydroxide
> works with free ProtonMail accounts.

---

## Requirements

- Windows 10/11
- [Go](https://go.dev/dl/) (to build the hydroxide binary)
- A ProtonMail account

---

## Setup

### 1. Build hydroxide

```powershell
go install github.com/emersion/hydroxide/cmd/hydroxide@latest
```

This installs `hydroxide.exe` to `%USERPROFILE%\go\bin`.

### 2. Log in to ProtonMail

```powershell
.\scripts\install-hydroxide-service-windows.ps1 auth -Username you@proton.me
```

You'll be prompted for your **real** Proton password and 2FA code (if
enabled). hydroxide stores an encrypted session in `%APPDATA%\hydroxide` and
prints a **bridge password** — copy it, you'll need it for your email client
(it is *not* your Proton password).

### 3. Install and start the auto-start task

```powershell
.\scripts\install-hydroxide-service-windows.ps1 install
.\scripts\install-hydroxide-service-windows.ps1 start
```

This registers a per-user Scheduled Task ("Hydroxide") that runs
`hydroxide serve` at logon, restarting it if it crashes. No admin rights
needed.

---

## Connecting your email client

| Setting | Value |
|---|---|
| IMAP host/port | `127.0.0.1` / `1143` |
| SMTP host/port | `127.0.0.1` / `1025` |
| CardDAV host/port | `127.0.0.1` / `8080` |
| Username | your ProtonMail address |
| Password | the **bridge password** printed by `hydroxide auth` |
| Encryption | None (loopback only) |

---

## Managing the service

```powershell
.\scripts\install-hydroxide-service-windows.ps1 status
.\scripts\install-hydroxide-service-windows.ps1 stop
.\scripts\install-hydroxide-service-windows.ps1 start
.\scripts\install-hydroxide-service-windows.ps1 uninstall
```

Logs: `%LOCALAPPDATA%\Hydroxide\logs\hydroxide.log`

---

## Re-authenticating

If your session expires or you change your Proton password, re-run:

```powershell
.\scripts\install-hydroxide-service-windows.ps1 stop
.\scripts\install-hydroxide-service-windows.ps1 auth -Username you@proton.me
.\scripts\install-hydroxide-service-windows.ps1 start
```

---

## Security

- hydroxide only listens on `127.0.0.1`
- Your Proton credentials are exchanged once during `auth` and never stored
  in this repo
- The bridge password is local-only, generated by hydroxide, separate from
  your Proton password
- hydroxide is a third-party, community-maintained project — review its
  source before trusting it with your account
